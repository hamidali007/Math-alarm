# Math Alarm — مشروع أندرويد

تطبيق منبّه عربي تجريبي مكتوب بـ Kotlin. يتضمن وقت منبّه يومي واحد، 3 مستويات للصعوبة، ومسألة واحدة لإيقاف الرنين، وإشعارًا بواجهة ملء الشاشة عند السماح بذلك.

## البناء
1. افتح المجلد MathAlarm في Android Studio (إصدار حديث يدعم Android Gradle Plugin 8.7.3 وJDK 17).
2. انتظر مزامنة Gradle عبر الإنترنت أول مرة.
3. اختر Build > Build APK(s)، ثم ثبّت ملف APK الناتج على هاتفك.
4. امنح إذن الإشعارات وإذن المنبّهات الدقيقة عند طلبهما. قد يلزم السماح بإشعارات ملء الشاشة من إعدادات الهاتف.
5. أوقف تقييد البطارية للتطبيق إذا كان جهازك يؤخر المنبّهات، واختبر الرنين على جهازك قبل الاعتماد عليه.

## حدود النسخة
- تصميم داكن بلمسات مرئية؛ التأثيرات ثلاثية الأبعاد الفعلية لم تُنفذ بعد.
- منبّه يومي واحد، وليس عدة منبّهات.
- قد تمنع سياسات أندرويد/الشركة المصنّعة ظهور الشاشة تلقائيًا؛ عندها افتح إشعار المنبّه.
- يمكن للمستخدم إيقاف الجهاز أو التطبيق من إعدادات النظام؛ لا يمكن منع ذلك.
- هذه ملفات مصدر مشروع قابلة للبناء، وليست APK مبنيًا أو مختبرًا على جهاز.
