# المحاسب — المرحلة الثالثة (نسخة تجريبية)

تطبيق Flutter عربي لإدارة عدة شركات منفصلة، مع قاعدة بيانات SQLite محلية.

## الجديد في المرحلة الثالثة
- إدارة العملاء والموردين لكل شركة.
- تعريف الأصناف والأسعار والمخزون بالوحدات الصحيحة.
- فاتورة بيع أو شراء لصنف واحد، نقدية أو آجلة.
- تحديث كمية المخزون داخل معاملة SQLite واحدة.
- تسجيل قيود محاسبية تلقائية ومتوازنة: المبيعات، المشتريات المخزنية، تكلفة البضاعة المباعة باستخدام متوسط تكلفة مرجح تقريبي، والذمم المدينة/الدائنة.
- منع بيع كمية أكبر من المتاح.
- ترقية قاعدة البيانات من الإصدار الثاني إلى الثالث مع إضافة حساب تكلفة البضاعة المباعة للشركات الموجودة.

## التشغيل
يتطلب Flutter SDK وأدوات بناء أندرويد مثبتة. هذا الأرشيف يحتوي على ملفات Flutter الأساسية فقط وليس مشروع Android مولّدًا أو APK.

```bash
flutter create --platforms=android,windows almohaseb_app
# انسخ pubspec.yaml و lib/main.dart من الأرشيف إلى المشروع المنشأ
flutter pub get
flutter run
```

## قيود مهمة
- لا يوجد حاليًا PDF أو فاتورة ضريبية أو دعم VAT أو مرتجعات أو خصومات أو تعدد بنود الفاتورة.
- لا يوجد نظام تحصيل/سداد للديون؛ القيود الآجلة تُسجل على حسابات إجمالية فقط ولا توجد كشوف حسابات فرعية أو أرصدة شركاء موثوقة.
- لا توجد مستودعات متعددة، جرد تسويات، وحدات كسور، أو معالجة شاملة لتكاليف المخزون.
- متوسط التكلفة تقريبي وتدوير التكلفة قد يسبب فروقات طفيفة؛ يلزم تدقيق قبل الاستخدام الحقيقي.
- جدول sync_outbox محلي فقط، ولا توجد خدمة مزامنة فعلية.
- عمليات المرحلة الثانية النقدية القديمة لا تؤثر في مخزون المرحلة الثالثة؛ لا تستخدم النوعين لنفس البضاعة.
- لم يتم بناء أو اختبار APK في هذه البيئة. لا تستخدم النسخة لأعمال محاسبية فعلية أو التزامات ضريبية.

## المرحلة الرابعة (تجريبية)
- الموظفون والراتب الأساسي والبدلات لكل شركة.
- حضور وانصراف محليان، مع تمييز مصدر التسجيل (مدير/موظف). أزرار الموظف تجريبية وغير محمية بتسجيل دخول؛ لا تستخدم لإثبات حضور حقيقي.
- احتساب مسير شهري للراتب مع إضافي وخصومات وسلف، ومنع تكرار المسير لنفس الموظف والشهر.
- لم يتم بعد ترحيل الرواتب إلى دفتر الأستاذ، أو صرفها، أو مزامنتها، أو إضافة صلاحيات المستخدمين والتوثيق.
- تم إصلاح ترتيب إنشاء الجداول عند التثبيت الجديد لتجنب تعارض مفاتيح SQLite الأجنبية.
- لا يزال التطبيق مصدر Flutter يحتاج إلى إنشاء مجلدات المنصات عبر `flutter create .` ثم `flutter pub get` و `flutter run`؛ لم يتم بناؤه أو اختباره على جهاز.

## المرحلة الخامسة: التقارير والتصدير PDF (نسخة أولية)
- أضيفت شاشة التقارير: ميزان المراجعة، قائمة الدخل، الميزانية العمومية، قائمة فواتير العملاء والموردين، مسير الرواتب، الحضور، والفواتير.
- التقارير مقيدة بمعرف الشركة وتقرأ قاعدة البيانات المحلية. الطباعة/الحفظ PDF باستخدام `pdf` و`printing` مع خط عربي مضمن (Noto Naskh Arabic).
- لا توجد حتى الآن فاتورة PDF ضريبية مستقلة؛ خيار «الفواتير» يصدر **قائمة الفواتير** وليس فاتورة نظامية مفصلة.
- قائمة الدخل والميزانية تقارير مبدئية: لا تتضمن إقفال الفترات أو التسويات أو إثبات الرواتب محاسبيًا؛ قد لا تعكس الأرقام الحقيقة الكاملة.
- «كشف العملاء والموردين» يعرض مجموع الفواتير الآجلة فقط؛ ليس كشف حساب مكتملًا ولا يحسم المدفوعات (لا توجد وظيفة تحصيل/سداد بعد).
- يعتمد التصدير على دعم الطباعة في نظام التشغيل؛ لا توجد ميزة إرسال/مشاركة مضمونة دون اختبار.
- لا يوجد Flutter SDK مثبت في بيئة إعداد الملفات؛ **لم يُنفذ flutter pub get أو تحليل Dart أو بناء APK**. يجب اختبار الكود وحل أي مشكلات توافق على بيئة Flutter فعلية.
- لإعداد مشروع المنصات من داخل المجلد: `flutter create --platforms=android,windows .` ثم `flutter pub get` ثم `flutter run`.


## المرحلة السادسة — تحضير وفحص المزامنة (لا توجد مزامنة سحابية بعد)
- أضيفت شاشة **حالة المزامنة المحلية** لكل شركة؛ تعرض عدد الأحداث غير المرسلة حسب النوع، وعدد السجلات في الجداول الرئيسية لتسهيل تدقيق التغطية.
- تعمل الشاشة محليًا وبدون شبكة، ولا تغير حالة `synced` ولا تزعم رفع أي بيانات.
- **مهم:** طابور `sync_outbox` الحالي لا يغطي جميع التعديلات؛ عمليات الحضور والرواتب وتعديل كميات المخزون تحتاج أحداثًا ذرية كاملة قبل تشغيل المزامنة.
- لم تنفذ بعد: مصادقة المستخدمين، عزل الشركات على الخادم، واجهة API، التحقق من الصلاحيات، إرسال واستقبال تغييرات، حل التعارضات، تشفير النسخ الاحتياطية، مزامنة الكمبيوتر.
- الخطوة التقنية التالية: بناء خادم موثق ومعاملات idempotent لكل حدث وتخزين إصدارات السجلات وتعارضاتها واختبار عمليات متعددة الأجهزة قبل تمكين زر المزامنة.
- هذا المشروع **مصدر Flutter فقط** ولم يتم اختبار البناء في بيئة Flutter.
